## 3. Design tokens established

File: `public/css/tokens.css`

| Token | Value | Role |
|-------|--------|------|
| `--navy` / `--navy-deep` | `#0b1c2c` / `#07141f` | Structural navy |
| `--accent` / `--accent-strong` | `#1b6b6e` / `#145457` | Restrained teal |
| `--accent-on-navy` | `#8ec4c2` | Teal on navy (eyebrows, nav hover) |
| `--surface` / `--surface-muted` | `#ffffff` / `#f4f3ef` | White / off-white reading |
| `--ink` / `--ink-muted` / `--ink-secondary` | `#14202b` / `#5c676f` / `#2c3640` | Primary / secondary text |
| `--ink-on-navy` | `#d5ddd9` | Body text on navy |
| `--line` | `#e4e2dc` | Thin structural rules |
| `--font-display` | Georgia / Palatino stack | Editorial headings |
| `--font-body` | Georgia stack | Body |
| `--font-ui` | Segoe UI / system-ui | Nav, eyebrows, labels |
| `--fs-h1` / `--fs-h2` / `--fs-body` | clamp 2.55–4.15rem / 1.85–2.65rem / 1.125rem | Type scale |
| `--lh-body` / `--lh-heading` | 1.7 / 1.12 | Line heights |
| `--max` / `--wide` / `--gutter` | 46rem / 72rem / clamp 1.25–2.25rem | Measure and gutters |
| `--space-section` | clamp 3.5–6.75rem | Vertical section rhythm |
| `--bp-nav` / `--bp-desktop` | 800px / 1024px | Documented breakpoints |

Prior `--gold` / `--gold-strong` remain as aliases to teal so existing section CSS consumes the new accent without a layout rewrite.

Reusable primitives: `.section-canvas`, `.section-structural`, `.section-muted`, `.container`, `.rule-top`, `.rule-block`.
