## 4. Architecture decision

**Choice:** static HTML/CSS/JS in `public/`, served by Python’s HTTP server, with `.replit` static deployment of `public/`.

This satisfies simplest-architecture, Replit portability, and the prohibition on database, auth, CMS, AI features, and backend services.

Recorded in `docs/nebula/architecture/website-v1.md`.
